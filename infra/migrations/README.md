# Database migrations

Alembic migrations, autogenerated from the ORM models in
[`libs/shared-models/shared_models/models.py`](../../libs/shared-models/shared_models/models.py).
The models are the source of truth; migrations are a generated diff against
them, not hand-authored schema.

## Setup

```bash
pip install alembic
pip install -e ../../libs/shared-models
```

## Generate a new migration after changing the models

```bash
cd infra/migrations
DATABASE_URL=postgresql+psycopg://ctplatform:ctplatform@localhost:5432/ctplatform \
  alembic revision --autogenerate -m "describe the change"
```

Always read the generated migration before committing it -- autogenerate
does not reliably detect every kind of change (e.g. column renames show up
as drop+add).

## Apply migrations

```bash
cd infra/migrations
DATABASE_URL=postgresql+psycopg://ctplatform:ctplatform@localhost:5432/ctplatform alembic upgrade head
```
