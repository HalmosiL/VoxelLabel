# CT Annotation Platform

A database management system for medical DICOM CT data and their
annotations. See [`ARCHITECTURE.md`](ARCHITECTURE.md) for the full design
rationale (schema, RBAC, Kubernetes topology, ingestion pipeline).

## Layout

```
services/
  ingestion-service/   DICOM upload, de-identification, async processing
  data-service/        Browse studies/series/instances, fetch pixel data
  annotation-service/  Create/list/review annotations
  admin-service/       Projects, memberships, de-identification profiles
libs/
  shared-models/       SQLAlchemy models + DB session (schema source of truth)
  shared-auth/         Keycloak JWT validation + project-role checks
infra/
  migrations/          Alembic migrations, autogenerated from shared-models
  k8s/                 Kubernetes manifests for the four services
```

Every service is independently runnable, testable, and documented -- see
each `services/*/README.md`.

## Running locally

```bash
cp .env.example .env   # adjust if needed
docker compose up --build
```

This starts Postgres, Redis, MinIO, a dev-mode Keycloak, and all four
services. Ports:

| Service | Port |
|---|---|
| ingestion-service | 8001 |
| data-service | 8002 |
| annotation-service | 8003 |
| admin-service | 8004 |
| Keycloak | 8080 |
| MinIO console | 9001 |

**First-time setup:**
1. `./infra/keycloak/setup-dev-realm.sh` -- provisions the `ct-platform` realm, client, and a test admin user (see `infra/keycloak/README.md`). Safe to re-run.
2. Generate and apply the initial DB migration -- see `infra/migrations/README.md`. (Already generated: `infra/migrations/versions/0e59bfd285e6_initial_schema.py` -- just run `make migrate` against a fresh database.)

## Running a single service outside Docker

See the `README.md` in each `services/<name>/` directory -- each documents
its own dependencies, env vars, and how to run its test suite in isolation.

## Running tests

```bash
make test              # all services
make test-ingestion    # one service
```

## Status

endpoint set per service are in place. Not yet implemented: Kubernetes
Ingress/cert wiring for a real domain, CI, dataset snapshot endpoints, and
the annotator DICOM viewer client (deferred -- see `ARCHITECTURE.md`).
